Postman: Authentication

1. Login Request
  • POST http://localhost:8080/auth
  • BODY (JSON): {"username":"admin", "password":"admin@123"}

Postman: Employee CRUD (MySQL)

These endpoints are Public. Base Path: /api/employees

1. Standard JPA Operations
  • GET /api/employees (List all)
  • POST /api/employees (Add new)
2. Native SQL Operations
  • GET /api/employees/native (Fetch all using SQL)
  • POST /api/employees/native (Insert using SQL)
  • PUT /api/employees/native/{id}?salary=90000 (Update salary)
